# PakPedia

Pakistan's complete information directory for Schools, Hospitals, Gold Rates, News & Newspapers.

## Features
- Schools & Hospitals directory with ratings and contact info
- Live Gold & Silver rates
- Pakistan news headlines + newspaper links
- SEO optimized (titles, meta, canonical, Schema.org)
- FAQ page for better GEO / AI visibility
- Google Analytics 4 integrated (`G-2HT635TZS5`)
- Mobile friendly & high performance

## Tech Stack
- React + Vite
- Tailwind CSS
- React Router
- React Helmet Async

## Deploy
```bash
npm install
npm run build
```
Then deploy the `dist` folder (or connect this repo to Vercel).
